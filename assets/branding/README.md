# SHERLOCKED original identity

Original SVG artwork created for this project on 13 November 2026. The silhouette is an invented Victorian detective, with a double-brim deerstalker, right-facing profile and curved pipe held at the mouth. It does not depict an actor or reuse supplied artwork.

- sherlocked-primary.svg: black emblem and wordmark for paper.
- sherlocked-emblem.svg: ivory compact emblem for the ink sidebar.
- sherlocked-monochrome.svg / sherlocked-ivory.svg: monochrome variants.
- sherlocked-forensic-red.svg: oxblood variant.
- favicon.svg: simplified small icon with mandatory hat and pipe.

All assets are self-contained and have accessible titles. The wordmark uses offline Cambria/Georgia fallbacks. The SVG path IDs identify the editable hat, face, coat and curved pipe.
